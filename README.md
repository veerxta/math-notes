# Math Notes

Repositori catatan kuliah pribadi untuk program studi **S1 Matematika**. Proyek ini digunakan untuk mendokumentasikan, merapikan, dan mengarsipkan materi perkuliahan secara terstruktur.

## Struktur Direktori

- `assets/` — File pendukung tampilan seperti CSS (`css/`), skrip JavaScript (`js/`), dan ikon (`icons/`).
- `templates/` — Template dasar untuk penulisan catatan kuliah.
- `courses/` — Catatan kuliah yang sudah dirapikan per mata kuliah:
  - `linear-algebra/` — Catatan mata kuliah Linear Algebra (Aljabar Linear).
  - `multivariable-calculus/` — Catatan mata kuliah Multivariable Calculus (Kalkulus Peubah Banyak).
  - `systems-mathematics/` — Catatan mata kuliah Systems Mathematics (Matematika Sistem).
  - `numerical-methods/` — Catatan mata kuliah Numerical Methods (Metode Numerik).
  - `operations-research-1/` — Catatan mata kuliah Operations Research 1 (Riset Operasi I).
  - `simulation-techniques/` — Catatan mata kuliah Simulation Techniques (Teknik Simulasi).
- `raw-materials/` — Materi mentah, referensi, atau coretan awal (diabaikan oleh Git).
