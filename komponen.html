Definisi, teorema, lemma, proposisi, akibat

Barisan Cauchy (Cauchy sequence)

Barisan bilangan real $(x_n)$ disebut barisan Cauchy jika untuk setiap $\varepsilon \gt 0$ terdapat $N \in \N$ sehingga $\abs{x_m - x_n} \lt \varepsilon$ untuk semua $m, n \ge N$.

Teorema dasar kalkulus

Jika $f$ kontinu pada $[a, b]$ dan $F$ adalah antiturunan $f$ pada $[a, b]$, yaitu $F'(x) = f(x)$ untuk setiap $x \in [a, b]$, maka

$$\int_a^b f(x)\,dx = F(b) - F(a).$$

Ketaksamaan segitiga

Untuk setiap $x, y \in \R$ berlaku $\abs{x + y} \le \abs{x} + \abs{y}$.

Setiap barisan real yang konvergen adalah barisan Cauchy.

Ketaksamaan segitiga terbalik

Untuk setiap $x, y \in \R$ berlaku $\bigl\lvert \abs{x} - \abs{y} \bigr\rvert \le \abs{x - y}$.

Contoh, catatan, peringatan

Memakai teorema dasar kalkulus

Antiturunan $x^2$ adalah $F(x) = \frac{x^3}{3}$, sehingga

$$\int_0^1 x^2\,dx = \left[\frac{x^3}{3}\right]_0^1 = \frac{1}{3} - 0 = \frac{1}{3}.$$

Turunan hasil bagi

Pada umumnya $\left(\dfrac{u}{v}\right)' \ne \dfrac{u'}{v'}$. Yang benar, untuk $v \ne 0$:

$$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}.$$

Bukti

Menurut Lemma 1, $\abs{x} = \abs{(x - y) + y} \le \abs{x - y} + \abs{y}$, sehingga $\abs{x} - \abs{y} \le \abs{x - y}$.

Dengan menukar peran $x$ dan $y$, diperoleh $\abs{y} - \abs{x} \le \abs{y - x} = \abs{x - y}$.

Jadi $-\abs{x - y} \le \abs{x} - \abs{y} \le \abs{x - y}$, yaitu $\bigl\lvert \abs{x} - \abs{y} \bigr\rvert \le \abs{x - y}$.

Lihat pembahasan

Pembahasan oleh Claude — perlu dicek

  1. Cari antiturunan: $F(x) = -\cos x$, karena $F'(x) = \sin x$.
  2. Fungsi $\sin x$ kontinu pada $[0, \pi]$, jadi teorema dasar kalkulus berlaku: $$\int_0^{\pi} \sin x\,dx = F(\pi) - F(0) = -\cos \pi - (-\cos 0) = 1 + 1 = 2.$$

Kode

Blok kode memakai <pre><code>. Isinya tidak dirender sebagai rumus, dan baris panjang bisa digeser ke samping.

def biseksi(f, a, b, tol=1e-6):
    """Akar f di [a, b]; syarat: f(a) dan f(b) berbeda tanda."""
    if f(a) * f(b) > 0:
        raise ValueError("f(a) dan f(b) harus berbeda tanda")
    while (b - a) / 2 > tol:
        c = (a + b) / 2
        if f(a) * f(c) <= 0:
            b = c
        else:
            a = c
    return (a + b) / 2

print(biseksi(lambda x: x**2 - 2, 1, 2))  # ≈ 1.414214
